`content/` 中的每個 `.md` 檔會自動對應一條路由。

## 路由對應

| 檔案 | 對應路由 |
|---|---|
| `content/index.md` | `/` |
| `content/about.md` | `/about` |
| `content/blog/index.md` | `/blog` |
| `content/blog/hello.md` | `/blog/hello` |
| `content/1.guide/2.installation.md` | `/guide/installation`(數字前綴僅用於排序) |

## Frontmatter

每個頁面都建議在 frontmatter 設定 `title` 與 `description`,Docus 會自動渲染為頁面標題區塊與 SEO meta:

```md [example.md]
---
title: Getting Started
description: 從撰寫 Markdown 到部署文件網站,只要幾分鐘。
---

## 子章節從這裡開始
```

::caution
**不要**在內文再寫一次 `# H1` 或同樣的描述段,否則 Docus 會渲染兩次(frontmatter 標題區塊 + 內文 H1)。內文應該直接從 `## 子標題` 開始。
::

## 常用 frontmatter 欄位

::field-group
  ::field{name="title" type="string"}
  頁面標題,顯示在標題區塊與 `<title>`。
  ::

  ::field{name="description" type="string"}
  頁面描述,顯示在標題下方與 SEO meta。
  ::

  ::field{name="layout" type="'default' | 'docs'"}
  指定 layout(通常不必設定,首頁預設 `default`、其餘預設 `docs`)。
  ::

  ::field{name="navigation" type="boolean | object"}
  `false` 隱藏此頁於側邊導覽;物件可指定 `title` / `icon` / `redirect`。
  ::

  ::field{name="seo" type="object"}
  覆寫 SEO meta,例如自訂 og:image、canonical。
  ::
::

## MDC 語法

除了純 Markdown,還可以用 MDC 語法呼叫 Vue 元件:

```md
::tip
這是一段提示。
::

:badge[New]
```

可用元件清單請見 [Components](/vue/components)。
