title: Configuration
description: 透過 app.config.ts 設定 Docus 5 的網站標題、SEO、header、社群連結與 GitHub 整合。
---

Docus 5 的設定全部寫在 `app.config.ts`,主要欄位都放在**頂層**,不再包在 `docus: {}` 內(這是與舊版 Docus 最大的不同)。

## 最小設定範例

```ts [app.config.ts]
export default defineAppConfig({
  docus: {
    locale: 'zh-TW'
  },
  seo: {
    title: 'JIANG Blog',
    description: '前端轉職'
  },
  header: {
    title: 'JIANG Blog'
  },
  socials: {
    github: 'viccjiang/jiangs_blog'
  },
  github: {
    owner: 'viccjiang',
    name: 'jiangs_blog',
    branch: 'main',
    rootDir: 'content'
  }
})
```

## 主要欄位

::field-group
  ::field{name="docus.locale" type="string"}
  介面語系。可選 `en`、`zh-TW`、`fr` 等(對應 `node_modules/docus/i18n/locales/`)。
  ::

  ::field{name="seo.title" type="string"}
  網站預設標題,作為各頁面 `<title>` 的 fallback。
  ::

  ::field{name="seo.description" type="string"}
  網站預設描述,用於 og/twitter meta。
  ::

  ::field{name="seo.titleTemplate" type="string"}
  標題模板,例如 `'%s · JIANG Blog'`。
  ::

  ::field{name="header.title" type="string"}
  navbar 左上文字。當 `header.logo` 沒設定時顯示。
  ::

  ::field{name="header.logo" type="object"}
  Logo 圖檔設定,包含 `light` / `dark` / `alt` / `class`。
  ::

  ::field{name="socials" type="Record<string, string>"}
  社群連結,例如 `{ github: 'owner/repo', x: 'handle' }`。
  ::

  ::field{name="github" type="object | false"}
  GitHub 整合,啟用「Edit this page」連結。欄位:`owner` / `name` / `branch` / `rootDir`。
  ::
::

## 加入 Logo 圖片

把圖檔放到 `public/`(例如 `public/logo.svg`),再設定:

```ts [app.config.ts]
export default defineAppConfig({
  header: {
    title: 'JIANG Blog',
    logo: {
      light: '/logo-light.svg',
      dark: '/logo-dark.svg',
      alt: 'JIANG Blog'
    }
  }
})
```
