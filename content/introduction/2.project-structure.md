## 目錄結構

```bash
content/                 # Markdown 內容,路徑即路由
  index.md               # 首頁
  introduction/
    _dir.yml             # 章節導覽與 metadata
    getting-started.md
public/                  # 靜態資源(圖片、favicon、logo)
app.config.ts            # Docus 主題設定
nuxt.config.ts           # Nuxt 設定
tsconfig.json            # TypeScript 設定
package.json
```

## 各檔案用途

::field-group
  ::field{name="content/" type="dir"}
  Markdown 內容根目錄。每個 `.md` 檔對應一條路由(`introduction/getting-started.md` → `/introduction/getting-started`)。詳見 [Writing Pages](/introduction/writing-pages)。
  ::

  ::field{name="content/_dir.yml" type="file"}
  章節層級的設定:導覽 icon、標題、跳轉目標(`navigation.redirect`)。每個章節資料夾都應該有一份。
  ::

  ::field{name="public/" type="dir"}
  靜態資源,以網站根目錄(`/`)直接存取。例如 `public/logo.svg` 對應 `/logo.svg`。
  ::

  ::field{name="app.config.ts" type="file"}
  Docus 主題設定。配置標題、SEO、header、socials、GitHub 整合等。詳見 [Configuration](/introduction/configuration)。
  ::

  ::field{name="nuxt.config.ts" type="file"}
  Nuxt 設定。`extends: ['docus']` 啟用 Docus 主題,模組與 runtime 設定也放在這裡。
  ::

  ::field{name="tsconfig.json" type="file"}
  TypeScript 設定,通常 extend Nuxt 自動產生的 `.nuxt/tsconfig.json`。
  ::
::

## 自訂擴充

若需要擴充主題,在專案根目錄新增以下目錄(Nuxt 4 慣例):

- `app/components/` — 自訂 Vue 元件,可在 markdown 中以 MDC 語法呼叫
- `app/layouts/` — 自訂版面
- `app/pages/` — 自訂 Vue 頁面(非 markdown)
- `app/composables/` — 自訂 composables

Docus 主題的元件來源在 `node_modules/docus/app/`,可作為覆寫參考。
