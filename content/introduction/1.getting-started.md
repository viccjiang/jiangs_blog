## 建立新專案

1. 使用官方 `create-docus` CLI 建立新專案：

```bash [npx]
npx create-docus my-docs
```

若要建立多語系版本，可加上 `-t i18n`。

2. 進入專案目錄並安裝相依套件：

::code-group

  ```bash [npm]
  cd my-docs
  npm install
  ```

  ```bash [yarn]
  cd my-docs
  yarn install
  ```

  ```bash [pnpm]
  cd my-docs
  pnpm install
  ```

::

3. 啟動開發伺服器：

::code-group

```bash [npm]
npm run dev
```

```bash [yarn]
yarn dev
```

```bash [pnpm]
pnpm run dev
```

::

::alert{type="success"}
✨ 完成後可在 <http://localhost:3000> 預覽網站。
::
